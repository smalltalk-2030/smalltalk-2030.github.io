# Chromebook を、みんなの手に。

Jekyll で作った、テキスト中心のクラウドファンディング構想サイトです。

## ローカルで確認

```sh
bundle install
bundle exec jekyll serve
```

その後 `http://127.0.0.1:4000/` を開きます。

## 最初に直す場所

`index.md` の以下を自分のものに変更してください。

- `YOUR-EMAIL@example.com`
- `https://github.com/YOUR-NAME/smalltalk-2030`

## 方針

- JavaScript なし
- 画像なし
- 外部フォントなし
- Jekyll のみ
- テキスト中心
- スマートフォンでも読みやすく

## GitHub Pages

リポジトリに置いて GitHub Pages から公開できます。
公開環境に合わせて Gemfile は調整してください。
