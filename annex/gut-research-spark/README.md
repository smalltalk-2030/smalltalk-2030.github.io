# 腸活研究の種火 — Jekyll 版

このディレクトリは Smalltalk-2030 の `annex/` に置く前提です。

- `index.html` は Jekyll front matter 付きの独立ページです。
- 見た目は Smalltalk-2030 本体と分けるため、`layout: null` と専用 CSS を使います。
- CSS はリポジトリルートの `assets/css/gut-research.css` に置きます。
- `research-notes.md` と `sources.md` は研究構想・参考資料のメモです。

ビルドや `bundle install` はこのディレクトリではなく、Smalltalk-2030 のリポジトリルートで行ってください。
