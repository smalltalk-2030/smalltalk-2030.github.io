<section class="origin wrap section-block" markdown="1">

01 / ORIGIN
{: .section-label }

<div class="two-col" markdown="1">
<div markdown="1">

## 始まりは、とても個人的な困りごと。

</div>
<div class="prose" markdown="1">

僕の動機のほとんどは、「困っている人を助けたい」です。そして、その「困っている人」は、大概まず僕です。

自分の生活の中で、カスピ海ヨーグルトに難消化性デキストリンを混ぜて食べるようになった。そこでふと考えました。

> これは本当に役に立っているのだろうか。  
> 役に立つなら、僕以外の困っている人にも伝えられないだろうか。

体験談を、そのまま健康情報として広めるのは違う。ならば、研究して確かめればいい。

</div>
</div>
</section>

<section class="questions wrap section-block" markdown="1">

02 / QUESTIONS
{: .section-label }

## 調べたいことは、まず三つ。

<div class="question-grid" markdown="1">

<div class="question-card" markdown="1">

Q1
{: .question-no }

### カスピ海ヨーグルト固有の効果はあるか。

普通のヨーグルトや、ヨーグルトをほとんど食べない人と比べて、長期的な違いがあるのか。

</div>

<div class="question-card" markdown="1">

Q2
{: .question-no }

### 難消化性デキストリンとの相乗効果はあるか。

それぞれ単独の効果を足した以上の変化が、組み合わせによって起こるのか。

</div>

<div class="question-card" markdown="1">

Q3
{: .question-no }

### 「誰に効くのか」まで分かるか。

便通、腸内細菌、食生活、年齢などによって、反応する人としない人に違いがあるのか。

</div>
</div>
</section>

<section class="design wrap section-block" markdown="1">

03 / DESIGN
{: .section-label }

<div class="two-col" markdown="1">
<div markdown="1">

## 大規模調査と、<br>小さくても厳密な試験を。

</div>
<div class="prose" markdown="1">

最終的には、多数の人を長期間追う疫学調査を目指したい。ただし「一緒に食べると相乗効果があるか」を調べるには、観察だけでは限界があります。

そこで、研究機関と相談しながら、次のような **2×2 の比較試験**も候補にします。

</div>
</div>

|  | デキストリン なし | デキストリン あり |
|---|---|---|
| **FC株 なし** | **A**<br>対照 | **B**<br>デキストリンのみ |
| **FC株 あり** | **C**<br>FC株のみ | **D**<br>FC株＋デキストリン |
{: .matrix }

D が A より良かった、だけでは「相乗効果」とは言いません。B と C の効果を踏まえ、組み合わせに特別な交互作用があるかを統計的に確かめます。
{: .matrix-note }

</section>

<section class="independence wrap section-block" markdown="1">

04 / INDEPENDENCE
{: .section-label }

<div class="independence-panel" markdown="1">
<div markdown="1">

THE MOST IMPORTANT RULE
{: .eyebrow .dark }

## 研究するのは、僕ではない。

</div>
<div class="prose" markdown="1">

研究主体は、大学・大学病院・公的研究機関など、倫理審査と研究管理ができる**独立した日本の研究機関**を想定します。

- 研究計画は専門家が作る。
- 必要な人数は統計的に決める。
- 倫理審査を受ける。
- 個人情報を適切に管理する。
- 解析方法をできるだけ事前に決める。
- 「効果なし」でも結果を公表する。
{: .check-list }

食品メーカーに協力をお願いする可能性はあります。しかし、研究結果を止めたり、都合の悪い結果を隠したりできる立場には置きません。

</div>
</div>
</section>

<section class="crowdfunding wrap section-block" markdown="1">

05 / CROWDFUNDING
{: .section-label }

<div class="two-col" markdown="1">
<div markdown="1">

## クラファンで集めたいのは、<br>「答え」ではなく研究の土台。

</div>
<div class="prose" markdown="1">

いきなり何万人もの長期研究をクラウドファンディングだけで賄うのではなく、まずは研究を始められる状態を作るために使う構想です。

</div>
</div>

1. **研究者を見つける**  
   栄養疫学、腸内細菌、臨床統計などの専門家とチームを作る。
2. **研究計画を作る**  
   何を、誰に、どのくらいの期間、どう測るのかを決める。
3. **倫理審査と事前登録**  
   研究として守るべき手続きを踏み、解析計画を透明にする。
4. **小規模な先行研究**  
   実行可能性を確かめ、必要なら本研究の設計を修正する。
5. **公的研究費・共同研究へ**  
   クラファンを「研究を全部買うお金」ではなく、次へ進むための火種にする。
{: .steps }

</section>

<section class="promise wrap section-block" markdown="1">

06 / PROMISE
{: .section-label }

## 最初から約束しておきたいこと。

<div class="promise-grid" markdown="1">
<div markdown="1">

**効くと決めつけない。**

出発点は仮説であって、結論ではありません。

</div>
<div markdown="1">

**「効かなかった」を隠さない。**

否定的な結果も、困っている人には役立つ情報です。

</div>
<div markdown="1">

**体験談と研究結果を混ぜない。**

個人の経験は研究の問いを生むことはあっても、証拠そのものにはしません。

</div>
<div markdown="1">

**できるだけ開く。**

研究計画、集計結果、解析方法を、可能な範囲で公開できる形を目指します。

</div>
</div>
</section>
