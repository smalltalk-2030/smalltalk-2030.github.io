# 腸活研究の種火

カスピ海ヨーグルトと難消化性デキストリンの健康影響を、独立した日本の研究機関と市民の力で確かめるための「まだクラファンではない」構想ページです。

## ファイル

- `index.html` — 本文
- `assets/style.css` — デザイン
- `research-notes.md` — 研究構想の要点
- `sources.md` — 今後確認・整備したい根拠資料の入口

## 使い方

ビルド不要です。`index.html` をそのままブラウザで開けます。
GitHub Pages に置く場合も、リポジトリ直下を公開対象にすれば動作します。

## デザイン方針

Smalltalk-2030 の現在の白地・テキスト中心の構成とは意図的に分け、
「発酵」「研究ノート」「市民科学」を連想する生成り・深緑・臙脂のカード型デザインにしています。
外部フォントや JavaScript は使っていません。

## 重要

このページは医学的助言、健康食品の広告、研究参加者募集、クラウドファンディング募集のいずれでもありません。
研究を実施する場合は、大学・大学病院・公的研究機関など、倫理審査と研究管理ができる研究機関を主体とする前提です。
